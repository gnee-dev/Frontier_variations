# Design rules for this repo

Apply these to every change, on every page (see variation-04b/README.md for the v2 tokens):

- **Buttons are consistent.** Use the site's shared `.btn` classes (primary: `.btn .btn--primary`, the same as "Join Frontier"); don't create one-off button styles.
- **Subtitles share one size and colour.** On v2: `--v2-fs-subtitle` (17px), weight 400, `--v2-text-muted`.
- **Small clickable tabs/toggles are identical**: same font, weight and padding everywhere (on v2, `.v2-chip`: 15px, 500, 0 18px). Selection changes colour only, never weight or size.
- **Minimum font size is 14px.** Nothing smaller.
